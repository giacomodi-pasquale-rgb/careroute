# CareRoute Pediatric v0.1

A mobile-first concept prototype for routing a parent to an appropriate type of pediatric care. The flow captures child age and care need, applies an emergency gate, filters ineligible facilities, and ranks the remaining demo options using travel, appropriateness, wait, quality, and capability factors.

## Safety and data notice

This is not a medical device, symptom checker, or source of medical advice. All facilities, names, locations, hours, capabilities, travel times, waits, quality values, and scores are fictional and illustrative. Do not use this prototype for real medical decisions. In an emergency, call 911 or seek emergency care.

## Run locally

Open `index.html` in a browser. No build step or dependencies are required.
